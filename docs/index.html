Text Tools

Useful text related functions that can be done on the selected text

About Text Tools

Text Tools is a collection of useful text-related functions which can be accessed within many apps inside the Android System by simply selecting text. The supported options appear in the context menu, making it incredibly easy to process text without switching apps.

View on GitHub

Key Features

WhatsApp Integration

Easily text any unsaved number in WhatsApp without adding it to your contacts.

Math Evaluation

Evaluate mathematical expressions inline and replace them with results.

Text Transformation

Change case, wrap text with brackets or quotes, and more.

Find & Replace

Quickly find and replace text within your selection.

Text Analysis

Get detailed statistics about characters, words, letters, and digits.

Number Analysis

Convert bases, find factors, prime info, and perform math transformations on numbers.

Text Templates

Create and apply custom text templates with your selected text as a parameter.

Smart Actions

Directly send emails, dial numbers, or open URLs found in text.
